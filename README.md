# Growtopia Client Decompilation Project
An attempt to decompile the second earliest (found) version of Growtopia that comes with support for all major platforms we really care about (V1.44)

# Why now?
Because no one had the balls ig

# Note!
This project aims to recreate the original source code to a semi-accurate degree by replicating the client's folder structure, programming style and similar details. The Growtopia client is not very known for exceptionally good performance or programming so don't expect much from that side.
